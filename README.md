# Nerdy Papers

Throw papers into the bin with a matching type. Complete the quota within 1 minute — then it grows. Every few throws pick a card: buff or debuff.

## How to play

- Match each paper to the bin of the same type.
- Finish the quota before the timer runs out — then a new, bigger round starts.
- Every few throws a card appears: pick a buff to help you or a debuff to spice things up.

## Controls

| Action      | Key            |
| ----------- | -------------- |
| Move        | W A S D        |
| Sprint      | Shift          |
| Look        | Mouse          |
| Interact    | E              |
| Throw       | G              |
| Debug menu  | F3             |
