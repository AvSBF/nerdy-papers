Физика бумаги

Бумажка — это RigidBody3D. Она падает, кувыркается и отскакивает. А когда её подбирают, физика на время «выключается» и включается ручной полёт в руку. Это самый интересный файл проекта.

1. Страховка от падения под пол

Каждый физический шаг Godot вызывает у тела _integrate_forces(state) — это «FixedUpdate» для RigidBody, с доступом к физическому состоянию.

Scripts/Paper/paper.gd (фрагмент)
class_name Paper
extends RigidBody3D

const KILL_Y : float = -0.5

func _integrate_forces(state: PhysicsDirectBodyState3D) -> void:
	if global_position.y < KILL_Y:
		print("найдена бумага под полом, удаление")
		queue_free()
		return
	# ...

Если бумажка провалилась ниже −0.5 метра — удаляем. Простой «kill plane». queue_free() — аналог Destroy(gameObject), но безопасный: удаление произойдёт в конце кадра.

2. Подбор: выключаем физику

Когда игрок жмёт E, Interactor вызывает pick_up(). Перед этим он сохраняет текущие слои столкновений в метаданные, чтобы потом вернуть их обратно.

Scripts/Paper/paper.gd
func pick_up(target: Node3D, flight_time: float) -> void:
	set_meta("pickup_layer", collision_layer)
	set_meta("pickup_mask", collision_mask)
	collision_layer = 0
	collision_mask = 0
	gravity_scale = 0.0
	can_sleep = false
	linear_velocity = Vector3.ZERO
	angular_velocity = Vector3.ZERO
	_held = false
	_flight_target = target
	_hold_point = target
	_flight_from = global_position
	_flight_from_basis = global_basis
	_flight_progress = 0.0
	_flight_time = flight_time
set_meta / get_meta

Метаданные — это способ прицепить к узлу любые данные «на лету». В проекте так запоминаются слои, чтобы восстановить их при броске. Аналог Dictionary прямо на объекте.

3. Полёт в руку

Пока _flight_target не null, тело каждый физический шаг принудительно ставится в промежуточную точку между стартом и целью. Прогресс растёт от 0 до 1, а ease() сглаживает движение.

Scripts/Paper/paper.gd (фрагмент)
	if _flight_target != null:
		_flight_progress = minf(_flight_progress + state.step / _flight_time, 1.0)
		var t := ease(_flight_progress, 0.5)

		var target_pos := _flight_target.global_position + _flight_target.global_basis * hold_offset
		var tform := state.transform
		tform.origin = _flight_from.lerp(target_pos, t)
		tform.basis = _flight_from_basis.slerp(_flight_target.global_basis, t)
		state.transform = tform
		state.linear_velocity = Vector3.ZERO
		state.angular_velocity = Vector3.ZERO

		if _flight_progress >= 1.0:
			_held = true
			_flight_target = null
			type_label.visible = show_label_while_held
			picked_up.emit(self)

Что тут важно понять:

  • state.step — длительность физического шага. Делим на _flight_time и получаем прирост прогресса. Аналог Time.fixedDeltaTime.
  • lerp — линейная интерполяция позиции; slerp — сферическая интерполяция поворота (плавный разворот).
  • Скорости обнуляются, чтобы движок не «боролся» с нами.
  • Когда прогресс дошёл до 1 — испускается сигнал picked_up, и Interactor добавляет бумагу в стопку.

В руке бумага каждый шаг «прилипает» к трансформу HoldPoint (дочерний узел камеры) плюс hold_offset — смещение в стопке.

5. Бросок

Scripts/Paper/paper.gd (фрагмент)
func drop(throw_velocity: Vector3) -> void:
	var hold_transform := global_transform
	reparent(get_tree().current_scene)
	global_transform = hold_transform
	_held = false
	_hold_point = null
	_flight_target = null
	show_label_while_held = true
	type_label.visible = false
	gravity_scale = 1.0
	can_sleep = true
	collision_layer = get_meta("pickup_layer", 1)
	collision_mask = get_meta("pickup_mask", 1)
	linear_velocity = throw_velocity

reparent() переносит бумагу в корень сцены, чтобы она не уехала вместе с рукой. Трансформ сохраняется вручную, а затем возвращается физика, слои и скорость броска.
