UI и твины

Интерфейс в Godot строится из Control-узлов внутри CanvasLayer. А анимации без ключевых кадров делаются твинами — одной строкой. Разберём отладочное меню и всплывающий «+1».

CanvasLayer и Control

CanvasLayer — это слой, который рисуется поверх 3D и не крутится вместе с камерой. Внутри него живут Control-узлы: кнопки, ползунки, тексты.

Из Unity

CanvasLayer ≈ Canvas в режиме Screen Space — Overlay. Контейнеры (VBoxContainer, HBoxContainer, MarginContainer) — это автоматическая раскладка: аналог Horizontal/Vertical Layout Group, но встроенный в типы узлов.

Отладочное меню

Полный файл — отличный пример работы с Control-узлами и сигналами кнопок:

Scripts/UI/debug_menu.gd
extends CanvasLayer

@onready var panel : PanelContainer = $Panel
@onready var spawn_count_slider : HSlider = $Panel/Margin/VBox/SpawnRow/SpawnCountSlider
@onready var spawn_count_value : Label = $Panel/Margin/VBox/SpawnRow/SpawnCountValue
@onready var spawn_button : Button = $Panel/Margin/VBox/SpawnRow/SpawnButton
@onready var max_held_slider : HSlider = $Panel/Margin/VBox/MaxHeldRow/MaxHeldSlider
@onready var max_held_value : Label = $Panel/Margin/VBox/MaxHeldRow/MaxHeldValue
@onready var delete_button : Button = $Panel/Margin/VBox/DeleteButton

@onready var interactor : Node = get_tree().current_scene.get_node("Player/Interactor")

func _ready() -> void:
	panel.visible = false
	spawn_count_slider.value_changed.connect(_on_spawn_count_changed)
	max_held_slider.value_changed.connect(_on_max_held_changed)
	spawn_button.pressed.connect(_on_spawn_pressed)
	delete_button.pressed.connect(_on_delete_pressed)
	_on_spawn_count_changed(spawn_count_slider.value)
	_on_max_held_changed(max_held_slider.value)

Что здесь стоит заметить:

  • Путь $Panel/Margin/VBox/... — это путь по дереву, как transform.Find("...").
  • value_changed и pressed — встроенные сигналы узлов, подключаются через connect().
  • Обработчики вызываются вручную в конце _ready(), чтобы подписи сразу показали начальные значения.

Горячая клавиша и курсор

Scripts/UI/debug_menu.gd (фрагмент)
func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed("debug_menu"):
		_toggle_menu()
		get_viewport().set_input_as_handled()
	elif event.is_action_pressed("ui_cancel") and panel.visible:
		_toggle_menu()
		get_viewport().set_input_as_handled()

func _toggle_menu() -> void:
	panel.visible = not panel.visible
	if panel.visible:
		Input.mouse_mode = Input.MOUSE_MODE_VISIBLE
	else:
		Input.mouse_mode = Input.MOUSE_MODE_CAPTURED

set_input_as_handled() говорит движку «этот ввод я забрал» — чтобы его не обработали другие узлы (например, камера или закрытие по Esc). А ещё при открытом меню курсор освобождается, чтобы можно было кликать по кнопкам.

Твины

Твин — это анимация свойства, создаваемая в коде. Никаких AnimationClip: пишешь create_tween() и цепочку изменений.

Scripts/Paper Storage/paper_storage.gd (фрагмент)
var move_tween := create_tween()
move_tween.tween_property(label, "position", target_position, LABEL_MOVE_TIME).set_trans(Tween.TRANS_QUAD).set_ease(Tween.EASE_OUT)

await anim_player.animation_finished
await get_tree().create_timer(LABEL_HOLD_TIME).timeout

var fade_tween := create_tween()
fade_tween.tween_property(label, "modulate:a", 0.0, LABEL_FADE_TIME)
await fade_tween.finished
label.queue_free()
  • tween_property(объект, "свойство", цель, время) — базовая операция.
  • set_trans / set_ease — форма кривой и способ входа/выхода (как AnimationCurve).
  • Два await подряд делают паузу: сначала ждём анимацию появления, потом выдержку, потом гасим прозрачность.
  • "modulate:a" — альфа-канал цвета: так плавно скрывают любой CanvasItem.
Параллельные твины — player_interactor.gd
var tween := create_tween()
for i in held_papers.size():
	var p := held_papers[i]
	tween.parallel().tween_property(p, "hold_offset", _stack_offset_for_index(i), RISE_TIME)
_throwing = false

parallel() запускает следующую операцию одновременно с предыдущей, а не после неё. Так вся стопка бумаг опускается синхронно.

Твин живёт до конца

Твин автоматически привязан к узлу и сам запускается. Если нужно остановить — tween.kill(). А await tween.finished ждёт завершения, как yield return tween.WaitForCompletion() в C#.
