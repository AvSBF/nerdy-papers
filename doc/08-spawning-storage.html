Спавн и хранение

Стол создаёт бумажки из сцены-префаба, а ящики ловят их зоной Area3D, считают и либо принимают, либо швыряют обратно игроку. Разберём все три файла.

1. Спавн: стол-раздатчик

Scripts/Paper Creating Table/paper_creator.gd
extends Node3D

@export var paper_scene : PackedScene
@export var variation_x : Vector2
@export var variation_y : Vector2

@export var initial_center_pos : Vector3 = Vector3(-0.8,4.356,0)

func spawn_paper() -> void:
	var paper := paper_scene.instantiate()
	paper.paper_type = randi_range(1, 4)
	paper.add_to_group("paper")
	add_child(paper)
	paper.position = _get_random_position()

func _get_random_position() -> Vector3:
	var new_pos := initial_center_pos
	new_pos.x += randf_range(variation_x.x,variation_x.y)
	new_pos.z += randf_range(variation_y.x,variation_y.y)
	return new_pos

@export var paper_scene : PackedScene — в инспекторе сюда перетаскивают paper.tscn. Это классический «префаб-слот» из Unity.

  • instantiate() создаёт узел, но он ещё не в дереве.
  • add_child() добавляет его как ребёнка — только теперь он живёт в мире.
  • Позиция задаётся после добавления, потому что до этого узел не в дереве.
  • randi_range(1, 4) даёт случайный тип; randf_range — случайное число с плавающей точкой.
Частая ошибка новичка

paper_scene.instantiate() без add_child() — узел существует, но не отображается и не обрабатывается. Это как создать GameObject и забыть про Instantiate в сцену.

2. Кнопка: анимация и await

Scripts/Paper Creating Table/table_button_press.gd
extends Node3D

@onready var moving_part : MeshInstance3D = $"Moving Part"
@onready var creator : Node3D = get_parent().get_node("Paper Creator")

@export var initial_position : float = 0.154
@export var minimum_position : float = 0.084
@export var wait_time : float = 0.3

var _is_pressed : bool = false

func interact():
	if _is_pressed:
		return
	_is_pressed = true

	moving_part.position.y = minimum_position
	creator.spawn_paper()
	await get_tree().create_timer(wait_time).timeout

	moving_part.position.y = initial_position
	_is_pressed = false

Interactor не знает, что такое кнопка — он просто вызывает interact() у узла в группе "button". Это «утиная типизация»: важен метод, а не тип. Флаг _is_pressed не даёт спамить кнопкой, пока идёт анимация.

3. Ящик: Area3D и сигнал body_entered

Area3D — это зона-триггер. Она не мешает движению, но сообщает, когда в неё что-то вошло. Подключение сигнала происходит в _ready():

Scripts/Paper Storage/paper_storage.gd
@onready var detect_area : Area3D = $DetectArea
@onready var count_label : Label3D = $CountLabel
@onready var type_label : Label3D = $TypeLabel

@export var paper_type : int = 1
@export var throw_speed : float = 10.0
@export var plus_one_label_scene : PackedScene

var count : int = 0

func _ready() -> void:
	detect_area.body_entered.connect(_on_body_entered)
	type_label.text = str(paper_type)
	_update_label()

func _on_body_entered(body: Node3D) -> void:
	if not body.is_in_group("paper"):
		return
	var is_same := _is_same_paper_type(body)
	if is_same:
		count += 1
		body.queue_free()
		_update_label()
		_spawn_plus_one_label()
	else:
		_throw_toward_player(body)

func _is_same_paper_type(paper : Node3D) -> bool:
	return paper.get_paper_type() == paper_type
Из Unity

detect_area.body_entered.connect(_on_body_entered) — это аналог OnTriggerEnter, но подключённый в коде. body_entered — сигнал самого Area3D, его не надо объявлять, он уже есть у узла.

Почему queue_free(), а не «просто удалить»?

Мы находимся внутри обработчика физического сигнала. Удалять узел прямо сейчас небезопасно — движок ещё работает с ним. queue_free() ставит удаление в очередь до конца кадра.

Возврат чужой бумаги

Scripts/Paper Storage/paper_storage.gd (фрагмент)
func _throw_toward_player(paper : Node3D) -> void:
	var player := get_tree().get_first_node_in_group("player") as Node3D
	if player == null:
		return
	var dir := (player.global_position - paper.global_position).normalized()
	dir.y = absf(dir.y)
	paper.set_deferred("linear_velocity", dir * throw_speed)
  • get_first_node_in_group("player") — как FindWithTag, но для групп.
  • dir.y = absf(dir.y) — заставляет бумагу лететь вверх, а не в пол.
  • set_deferred("linear_velocity", ...) — «изменить свойство, когда движок будет готов». Физику нельзя менять прямо в колбэке столкновения.

Интерактив: ящики и типы

Наспавни бумажек, выбери одну и кликни по ящику. Совпал тип — ящик примет и покажет «+1». Не совпал — бумага полетит обратно.
