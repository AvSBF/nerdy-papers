Жадность

Квота растёт на случайное число: начальство требует больше бумажек, чем планировалось.

buff_id: "greed" дебафф · красная весь раунд · стакается

Эффект

➕

quota_target плюс случайное число (30–70)

Зеркало «Экономии»: apply_buff("greed") увеличивает quota_target на случайное число от 30 до 70. Каждый новый выбор снова поднимает планку.

До выбораquota_target = 300например
После выбора300 + 30..70становится 330–370

Схема работы

1. Выборapply_buff("greed").
→
2. Ростquota_target += randi_range(30, 70).
→
3. UIdeposits_changed.emit — планка подросла.

План внедрения

  1. Scripts/Round/round_controller.gd

    Рост квоты

    Та же константа, что у «Экономии», только со знаком плюс. Нижняя граница не нужна, верхняя — нет, квота просто растёт.

    round_controller.gd — жадность
    const QUOTA_RAISE_MIN : int = 30
const QUOTA_RAISE_MAX : int = 70

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"greed":
			var raise := randi_range(QUOTA_RAISE_MIN, QUOTA_RAISE_MAX)
			quota_target += raise
			deposits_changed.emit(total_deposited, buff_threshold)

Интерактив: планка растёт

Жми «Выбрать дебафф» — квота подскочит на случайное число.

интерактивквота растёт

Как проверить в игре

  1. Выбери «Жадность» — число в панели квоты должно прыгнуть вверх.
  2. Выбери ещё раз — снова вырастет на случайное число.
