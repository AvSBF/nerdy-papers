Короткая рука

Дальность взаимодействия падает. Подходить к бумажкам и кнопкам придётся вплотную.

buff_id: "short_arm" дебафф · красная весь раунд · стакается реализовано

Эффект

✊

interaction_distance − 0.5, минимум 1.0 м

Зеркало «Длинной руки»: 3.0 → 2.5 → 2.0. Пол подбирать с пола и кнопки нажимать придётся с близкого расстояния.

Без дебаффа3.0 мinteraction_distance
1-й выбор2.5 м−0.5

Схема работы

1. Выборapply_buff("short_arm").
→
2. Минусinteraction_distance −= 0.5, минимум 1.0.
→
3. РейкастЦель ищется на новой дистанции.

План внедрения

  1. Scripts/Round/round_controller.gd

    Ветка в apply_buff()

    Живёт в том же блоке, что «Длинная рука». Нижняя граница не даёт «обнять» бумажку невозможно близко.

    round_controller.gd — дальность
    const ARM_STEP : float = 0.5
const ARM_MIN : float = 1.0
var interaction_distance : float = 3.0

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"long_arm":
			interaction_distance += ARM_STEP
		"short_arm":
			interaction_distance = maxf(ARM_MIN, interaction_distance - ARM_STEP)
  2. Scripts/Player/player_interactor.gd

    Читаем из раунда

Как проверить в игре

  1. Выбери «Короткую руку».
  2. Попробуй подобрать бумажку с привычного расстояния — подсказка должна появляться позже.
