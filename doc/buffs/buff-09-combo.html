Комбо

Точная серия награждается: с третьей подряд правильно засчитанной бумажки каждая следующая приносит дополнительное очко. Промах — серия обнуляется.

buff_id: "combo" бафф · зелёная весь раунд · не стакается реализовано

Эффект

🔥

Серия из 3+ точных → +1 очко за бумажку

В RoundController копится combo_streak. Когда серия достигает 3, каждая следующая правильная бумажка добавляет points_per_paper + 1. Промах (чужая бумажка в урне) сбрасывает серию.

Серия 1–2обычные очкиpoints_per_paper
Серия 3++1 очкоpoints_per_paper + 1

Схема работы

1. ЗакидЯщик шлёт paper_deposited.
→
2. Серияcombo_streak += 1. Дошла до 3 — включился бонус.
→
3. ПромахЧужая бумажка → wrong_paper → серия в 0.

signal wrong_paper

	if not body.is_in_group("paper"):
		return
	if _is_same_paper_type(body):
		# ... засчитываем
	else:
		_throw_toward_player(body)

  2. Scripts/Round/round_controller.gd

    Серия и бонус

    round_controller.gd — комбо
    const COMBO_THRESHOLD : int = 3
var combo_enabled : bool = false
var combo_streak : int = 0

func _ready() -> void:
	# ...
	for storage in get_tree().get_nodes_in_group("paper_storage"):
		storage.paper_deposited.connect(_on_paper_deposited)
		storage.wrong_paper.connect(_on_wrong_paper)

func _on_paper_deposited(_count: int) -> void:
	combo_streak += 1
	var bonus := 0
	if combo_enabled and combo_streak >= COMBO_THRESHOLD:
		bonus = 1
	total_deposited += points_per_paper + bonus
	deposits_changed.emit(total_deposited, buff_threshold)
	# ...

func _on_wrong_paper() -> void:
	combo_streak = 0

Интерактив: держи серию

Кидай правильно и не мажь. С 3-й бумажки подряд очки идут с бонусом.

интерактивсерия и бонус

Как проверить в игре

  1. Выбери «Комбо».
  2. Кинь 2 бумажки в правильные урны — очки обычные.
  3. С 3-й бумажки прогресс квоты должен прыгать на 1 больше.
  4. Кинь бумажку в чужую урну — бонус должен пропасть до следующей серии из 3.
