Слабый бросок

Бумага вылетает вяло. Дальние урны придётся обходить ближе — или кидать навесом.

buff_id: "weak_throw" дебафф · красная весь раунд · стакается реализовано

Эффект

🪶

throw_speed − 1, минимум 2 ед/с

Зеркало «Мощного броска»: 5 → 4 → 3. Пол медленнее нельзя — иначе бумага не долетит даже до ближней урны.

Без дебаффа5 ед/сthrow_speed
1-й выбор4 ед/с−1
2-й выбор3 ед/с−1

Схема работы

1. Выборapply_buff("weak_throw").
→
2. Минусthrow_speed −= 1, минимум 2.
→
3. БросокБумага улетает медленнее.

План внедрения

  1. Scripts/Round/round_controller.gd

    Ветка в apply_buff()

    round_controller.gd — бросок
    const THROW_STEP : float = 1.0
const THROW_MIN : float = 2.0
var throw_speed : float = 5.0

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"power_throw":
			throw_speed += THROW_STEP
		"weak_throw":
			throw_speed = maxf(THROW_MIN, throw_speed - THROW_STEP)
  2. Scripts/Player/player_interactor.gd

    Используем скорость из раунда

    player_interactor.gd — бросок
    if is_instance_valid(paper):
	paper.drop(-camera.global_transform.basis.z * _round.throw_speed)
  3. Scripts/Round/round_controller.gd

    Сброс в новом раунде

    round_controller.gd — reset_round()
    func reset_round() -> void:
	throw_speed = 5.0

Интерактив: слабый бросок

Жми «Бросить» — чем слабее бросок, тем короче полёт. Урна на 6 метрах.

интерактивдальность полёта

Как проверить в игре

  1. Выбери «Слабый бросок».
  2. Кинь в дальнюю урну с прежнего места — бумага должна не долетать.
  3. Убедись, что минимум в 2 ед/с работает — бросок не становится нулевым.
