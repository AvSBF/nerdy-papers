Автоматизация

Кнопка стола-раздатчика возвращается быстрее. Меньше простаиваешь — больше бумажек в минуту.

buff_id: "automation" бафф · зелёная весь раунд · стакается реализовано

Эффект

⚙️

Кулдаун кнопки ×0.7 за выбор

После нажатия кнопка ждёт wait_time (0.3 c) и поднимается. Бафф уменьшает это время множителем: 0.3 → 0.21 → 0.15 (потолок).

Без баффа0.30 cwait_time
1-й выбор0.21 c×0.7
2-й выбор0.15 c×0.7 (потолок)

Схема работы

1. Выборapply_buff("automation").
→
2. Множительbutton_cooldown_multiplier *= 0.7, минимум 0.5.
→
3. КнопкаРаздатчик ждёт wait_time × множитель.

План внедрения

  1. Scripts/Round/round_controller.gd

    Множитель кулдауна

    round_controller.gd — кулдаун
    const COOLDOWN_FLOOR : float = 0.5
var button_cooldown_multiplier : float = 1.0

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"automation":
			button_cooldown_multiplier = maxf(
				COOLDOWN_FLOOR,
				button_cooldown_multiplier * 0.7
			)
  2. Scripts/Paper Creating Table/table_button_press.gd

    Ждём меньше

    table_button_press.gd — таймер
    var _round : Node

func _ready() -> void:
	_round = get_tree().get_first_node_in_group("round_controller")

func interact():
	if _is_pressed:
		return
	_is_pressed = true
	moving_part.position.y = minimum_position
	creator.spawn_paper()
	var cooldown := wait_time * _round.button_cooldown_multiplier
	await get_tree().create_timer(cooldown).timeout
	moving_part.position.y = initial_position
	_is_pressed = false
  3. Scripts/Round/round_controller.gd

    Сброс в новом раунде

    round_controller.gd — reset_round()

	button_cooldown_multiplier = 1.0

Интерактив: кнопка-раздатчик

Нажми «Нажать кнопку» — бумажка появится после кулдауна. Чем больше баффов, тем быстрее кнопка готова.

интерактивкулдаун кнопки

Как проверить в игре

  1. Выбери «Автоматизацию».
  2. Нажми кнопку стола — плашка должна вернуться заметно быстрее.
  3. Выбери ещё раз — разница станет меньше (потолок).
