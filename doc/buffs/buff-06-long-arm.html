Длинная рука

Дальность взаимодействия растёт: бумажки и кнопки можно хватать с большего расстояния.

buff_id: "long_arm" бафф · зелёная весь раунд · стакается

Эффект

🦾

interaction_distance +0.5 за выбор

Рейкаст из камеры бьёт на interaction_distance. Бафф увеличивает его: 3.0 → 3.5 → 4.0. Комфортнее подбирать с пола и жать кнопки без точного прицеливания.

Без баффа3.0 мinteraction_distance
1-й выбор3.5 м+0.5
2-й выбор4.0 м+0.5

Схема работы

1. Выборapply_buff("long_arm").
→
2. Дальностьinteraction_distance += 0.5.
→
3. РейкастИнтерактор ищет цель на новую дистанцию.

План внедрения

  1. Scripts/Round/round_controller.gd

    Дальность

    round_controller.gd — дальность
    const ARM_STEP : float = 0.5
const ARM_MIN : float = 1.0
var interaction_distance : float = 3.0

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"long_arm":
			interaction_distance += ARM_STEP
		"short_arm":
			interaction_distance = maxf(ARM_MIN, interaction_distance - ARM_STEP)
  2. Scripts/Player/player_interactor.gd

    Читаем из раунда

    Экспорт interaction_distance заменяется на значение из раунда.

    player_interactor.gd — рейкаст
    var _round : Node

func _find_target() -> Node:
	return InteractionRaycast.get_node_in_front(
		camera,
		_round.interaction_distance,
		func(node : Node) -> bool:
			for group in GROUPS:
				if node.is_in_group(group):
					return true
			return false,
		interaction_mask
	)

Как проверить в игре

  1. Выбери «Длинную руку».
  2. Встань чуть дальше от бумажки и подойди к ней с большего расстояния — подсказка «E» должна появляться раньше.
  3. Проверь, что кнопка стола нажимается издалека.
