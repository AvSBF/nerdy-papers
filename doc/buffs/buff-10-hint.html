Подсказчик

Когда в руке бумажка, урна с её типом подсвечивается. Не приходится бегать и всматриваться в цифры на ящиках.

buff_id: "hint" бафф · зелёная весь раунд · не стакается

Эффект

💡

Подсветка правильной урны

Урны в группе paper_storage получают метод set_hint(enabled). Небольшой контроллер следит за сигналом held_paper_changed и подсвечивает урны, чей тип совпадает с типом бумажки в руке.

Без баффатип на этикеткечитай сам
С баффомподсветкацель видна сразу

Схема работы

1. Выборapply_buff("hint") — hint_enabled = true.
→
2. ПодборИгрок взял бумажку — сигнал held_paper_changed.
→
3. ПодсветкаУрны с нужным типом включают индикатор.
→
4. БросокРука пуста — подсветка гаснет.

План внедрения

  1. Scripts/Paper Storage/paper_storage.gd

    Метод подсветки

    Индикатором может быть светящийся материал или Label3D. Метод просто вкл/выкл.

    paper_storage.gd — подсветка
    @onready var hint_light : OmniLight3D = $HintLight

func set_hint(enabled: bool) -> void:
	hint_light.visible = enabled
  2. Scripts/UI/hint_controller.gd (новый)

    Контроллер подсказок

    Слушает сигнал held_paper_changed интерактора. Тип бумажки в руке определяет, какие урны подсвечивать.

    hint_controller.gd
    extends Node

var _round : Node
var _storages : Array[Node] = []

func _ready() -> void:
	_round = get_tree().get_first_node_in_group("round_controller")
	_storages = get_tree().get_nodes_in_group("paper_storage")
	var player := get_tree().get_first_node_in_group("player")
	player.interactor.held_paper_changed.connect(_on_held_changed)

func _on_held_changed(paper: Node) -> void:
	if not _round.hint_enabled:
		return
	var wanted := -1
	if paper != null:
		wanted = paper.paper_type
	for storage in _storages:
		storage.set_hint(storage.paper_type == wanted)
  3. Scripts/Round/round_controller.gd

    Включение и сброс

    round_controller.gd — hint
    var hint_enabled : bool = false

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"hint":
			hint_enabled = true

func reset_round() -> void:
	hint_enabled = false

Как проверить в игре

  1. Выбери «Подсказчик».
  2. Возьми бумажку — правильная урна должна загореться.
  3. Брось или выбрось бумажку — подсветка должна погаснуть.
