Бонусные очки за бумажку

Обычно каждая внесённая бумажка даёт +1 очко к прогрессу раунда. Этот бафф временно повышает цену бумажки: пока он активен, один закид приносит +2 очка.

buff_id: "extra_points" бафф · зелёная длительность: 5 закидываний

Эффект

✚

Каждая бумажка приносит ×2 очков

Множитель живёт в RoundController как переменная points_per_paper. Бафф поднимает её с 1 до 2 на следующие 5 закидов, потом она возвращается к 1. Сброс — и при новом раунде.

Без баффа1 очко / закидtotal_deposited += 1
С баффом2 очка / закидtotal_deposited += 2

Схема работы

Логика простая: ящик по-прежнему шлёт сигнал «бумажка засчитана», а решает, сколько очков это стоит, уже RoundController. Бафф лишь меняет его переменную.

1. ЗакидЯщик шлёт paper_deposited.
→
2. ОчкиRoundController прибавляет points_per_paper (1 или 2).
→
3. РасходСчётчик жизни баффа уменьшается. Дошёл до 0 — множитель падает в 1.
→
4. UIПрогресс квоты обновляется сам: он читает total_deposited.
Из Unity

Это аналог «статов»: points_per_paper — как int-переменная на GameManager, а apply_buff() — метод, который её меняет с таймером возврата. Всё остальное (ящик, UI) подписывается на сигналы и не знает о баффе вообще.

План внедрения

  1. Scripts/Round/round_controller.gd

    Считаем очки через множитель

    Заводим переменные и меняем одно прибавление. Счётчик buff_uses_left возвращает множитель в норму, когда бафф «выдохся».

    round_controller.gd — множитель очков
    var points_per_paper : int = 1
var buff_uses_left : int = 0

const EXTRA_POINTS_USES : int = 5   # сколько закидов живёт бафф

func _on_paper_deposited(_count: int) -> void:
	total_deposited += points_per_paper   # было: += 1
	deposits_changed.emit(total_deposited, buff_threshold)
	if total_deposited >= buff_threshold:
		buff_required_reached.emit()
	if total_deposited >= quota_target:
		quota_reached.emit()
	if buff_uses_left > 0:
		buff_uses_left -= 1
		if buff_uses_left == 0:
			points_per_paper = 1          # бафф закончился
  2. Scripts/Round/round_controller.gd

    Метод apply_buff()

    Одна точка входа для всех будущих баффов: по buff_id решаем, что менять. Пока — только этот эффект.

    round_controller.gd — применение баффа
    func apply_buff(buff_id: String) -> void:
	match buff_id:
		"extra_points":
			points_per_paper = 2
			buff_uses_left = EXTRA_POINTS_USES
  3. Scripts/UI/buff_card_manager.gd

    Настоящая карточка вместо заглушки

    В GOOD_POOL появляется запись с buff_id, а при клике менеджер передаёт бафф в RoundController.

    buff_card_manager.gd — карточка и выбор
    const GOOD_POOL : Array[Dictionary] = [
	{"title": "Бонусные очки", "desc": "Каждая бумажка приносит +1 очко (×2).",
	 "buff_id": "extra_points"},
	# ... остальные заглушки
]

func _on_card_pressed(card: BuffCard) -> void:
	card_chosen.emit(card.card_type)
	if _round != null:
		if not card.buff_id.is_empty():
			_round.apply_buff(card.buff_id)
		_round.roll_required()
	_hide_cards()
  4. Scripts/UI/buff_card.gd

    Карточка хранит buff_id

    Сейчас карточка знает только card_type. Добавляем поле, чтобы менеджер при клике понял, какой именно бафф выбран.

    buff_card.gd — поле buff_id
    var buff_id : String = ""

func setup(data: Dictionary) -> void:
	card_type = str(data.get("type", "green"))
	buff_id = str(data.get("buff_id", ""))
	# ...
  5. Scripts/Round/round_controller.gd

    Сброс в новом раунде

    Чтобы бафф не переживал раунд, возвращаем множитель в 1 в reset_round().

    round_controller.gd — сброс
    func reset_round() -> void:
	points_per_paper = 1
	buff_uses_left = 0
	quota_target = 3
	total_deposited = 0
	# ...

Интерактив: 1 против 2 очков за бумажку

Жми «Закинуть бумажку» и следи за очками. Потом включи бафф — следующие 5 бумажек принесут по 2 очка.

интерактивмножитель очков за закид

Как проверить в игре

  1. Запусти Scenes/World.tscn.
  2. Кидай бумажки в ящик, пока не выпадут карточки (от 3 до 5 закидов).
  3. Выбери зелёную карточку «Бонусные очки».
  4. Следующие 5 бумажек должны прыгать прогресс на 2, а не на 1.
  5. Проверь, что после 5 закидов счёт снова идёт по 1, а в новом раунде бафф не работает.
