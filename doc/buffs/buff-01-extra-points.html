Бонусные очки за бумажку

Обычно каждая внесённая бумажка даёт +1 очко к прогрессу раунда. Этот бафф повышает цену бумажки до конца раунда. Выберешь его снова — бонус стакнется и станет ещё больше.

buff_id: "extra_points" бафф · зелёная весь раунд · стакается

Эффект

✚

Каждая бумажка приносит на 1 очко больше

Бонус живёт в RoundController как переменная points_per_paper. Бафф увеличивает её до конца раунда: выбрал один раз — 1 → 2, выбрал снова — 2 → 3 и так далее.

Без баффа1 очко / закидtotal_deposited += 1
После 1-го выбора2 очка / закидpoints_per_paper = 2
После 2-го выбора3 очка / закидpoints_per_paper = 3

Схема работы

Логика простая: ящик по-прежнему шлёт сигнал «бумажка засчитана», а решает, сколько очков это стоит, уже RoundController. Бафф лишь меняет его переменную.

1. ЗакидЯщик шлёт paper_deposited.
→
2. ОчкиRoundController прибавляет points_per_paper (1, 2, 3…).
→
3. Выбор сноваБафф выпал ещё раз — points_per_paper += 1. Бонус растёт.
→
4. UIПрогресс квоты обновляется сам: он читает total_deposited.
Из Unity

Это аналог «статов»: points_per_paper — как int-переменная на GameManager, а apply_buff() — метод, который её увеличивает. Бафф действует весь раунд, а повторный выбор просто прибавляет ещё +1. Всё остальное (ящик, UI) подписывается на сигналы и не знает о баффе вообще.

План внедрения

  1. Scripts/Round/round_controller.gd

    Считаем очки через бонус

    Заводим переменную points_per_paper и меняем одно прибавление. Никаких таймеров и счётчиков жизни — бонус действует до конца игры.

    round_controller.gd — очки за бумажку
    var points_per_paper : int = 1

func _on_paper_deposited(_count: int) -> void:
	total_deposited += points_per_paper   # было: += 1
	deposits_changed.emit(total_deposited, buff_threshold)
	if total_deposited >= buff_threshold:
		buff_required_reached.emit()
	if total_deposited >= quota_target:
		quota_reached.emit()
  2. Scripts/Round/round_controller.gd

    Метод apply_buff() — с накоплением

    Одна точка входа для всех будущих баффов: по buff_id решаем, что менять. Повторный выбор этого же баффа не сбрасывает значение, а прибавляет ещё +1.

    round_controller.gd — применение баффа
    func apply_buff(buff_id: String) -> void:
	match buff_id:
		"extra_points":
			points_per_paper += 1   # 1 → 2 → 3 → ...
  3. Scripts/UI/buff_card_manager.gd

    Настоящая карточка вместо заглушки

    В GOOD_POOL появляется запись с buff_id, а при клике менеджер передаёт бафф в RoundController.

    buff_card_manager.gd — карточка и выбор
    const GOOD_POOL : Array[Dictionary] = [
	{"title": "Бонусные очки", "desc": "Каждая бумажка приносит +1 очко.",
	 "buff_id": "extra_points"},
	# ... остальные заглушки
]

func _on_card_pressed(card: BuffCard) -> void:
	card_chosen.emit(card.card_type)
	if _round != null:
		if not card.buff_id.is_empty():
			_round.apply_buff(card.buff_id)
		_round.roll_required()
	_hide_cards()
  4. Scripts/UI/buff_card.gd

    Карточка хранит buff_id

    Сейчас карточка знает только card_type. Добавляем поле, чтобы менеджер при клике понял, какой именно бафф выбран.

    buff_card.gd — поле buff_id
    var buff_id : String = ""

func setup(data: Dictionary) -> void:
	card_type = str(data.get("type", "green"))
	buff_id = str(data.get("buff_id", ""))
	# ...
  5. Scripts/Round/round_controller.gd

    Сброс в новом раунде

    Бафф живёт весь раунд, но не дольше. Когда начинается новый забег, reset_round() возвращает бонус в норму.

    round_controller.gd — сброс раунда
    func reset_round() -> void:
	points_per_paper = 1
	quota_target = 3
	total_deposited = 0
	buff_threshold = 0
	roll_required()
Правило всех баффов

Баффы не бывают на время. Каждый действует до конца раунда, то есть до проигрыша (не выполнил квоту). Повторный выбор баффа усиливает его, а новый раунд обнуляет всё.

Интерактив: бонус растёт с каждым выбором

Жми «Закинуть бумажку» и следи за очками. Выбирай бафф сколько угодно раз — каждый выбор навсегда добавляет +1 очко за закид.

интерактивочки за закид

Как проверить в игре

  1. Запусти Scenes/World.tscn.
  2. Кидай бумажки в ящик, пока не выпадут карточки (от 3 до 5 закидов).
  3. Выбери зелёную карточку «Бонусные очки».
  4. Теперь каждая бумажка должна добавлять 2 очка вместо 1.
  5. Выбери этот бафф ещё раз — каждая бумажка должна давать уже 3 очка, и так дальше.
