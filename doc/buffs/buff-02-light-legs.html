Лёгкие ноги

Увеличивает скорость передвижения на 25% за каждый выбор. Носиться между столами станет быстрее, но и прицельно бросать на скорости — сложнее.

buff_id: "light_legs" бафф · зелёная весь раунд · стакается

Эффект

⚡

Скорость × (1 + 0.25 за выбор)

Множитель speed_multiplier живёт в RoundController и прибавляется на 0.25 за каждый выбор. Скрипт движения умножает на него базовую скорость игрока.

Без баффа×1.00move_speed
1-й выбор×1.25move_speed × 1.25
2-й выбор×1.50move_speed × 1.50

Схема работы

1. ВыборКарточка выбрана — apply_buff("light_legs").
→
2. Множительspeed_multiplier += 0.25.
→
3. Движениеplayer_movement умножает move_speed на множитель.
→
4. БегИгрок двигается быстрее. Выбор снова — ещё быстрее.
Из Unity

Аналог модификатора стата: speed_multiplier — как float на GameManager, который применяется к moveSpeed персонажа каждый кадр.

План внедрения

  1. Scripts/Round/round_controller.gd

    Множитель скорости + apply_buff()

    Здесь же живёт и красный «Тяжёлые ноги» — тот же множитель, только вниз, с потолком, чтобы скорость не уходила в ноль.

    round_controller.gd — скорость
    const SPEED_STEP : float = 0.25
var speed_multiplier : float = 1.0

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"light_legs":
			speed_multiplier += SPEED_STEP
		"heavy_legs":
			speed_multiplier = maxf(0.25, speed_multiplier - SPEED_STEP)
  2. Scripts/Player/player_movement.gd

    Применяем множитель

    Одна строка: берём ссылку на раунд в _ready() и умножаем базовую скорость.

    player_movement.gd — применение
    var _round : Node

func _ready() -> void:
	_round = get_tree().get_first_node_in_group("round_controller")
	# ...

func _physics_process(_delta: float) -> void:
	# ...
	var speed = controller.move_speed * _round.speed_multiplier
	if Input.is_action_pressed("sprint"):
		speed *= controller.sprint_multiplier
  3. Scripts/Round/round_controller.gd

    Сброс в новом раунде

    round_controller.gd — reset_round()
    func reset_round() -> void:
	speed_multiplier = 1.0
	# ...

Интерактив: беги и выбирай бафф

Зажми кнопку мыши на поле — человечек побежит к урне. Выбирай «Лёгкие ноги» и смотри, как растёт скорость.

Как проверить в игре

  1. Запусти Scenes/World.tscn, добудь карточки бросками.
  2. Выбери «Лёгкие ноги» — игрок должен заметно ускориться.
  3. Выбери ещё раз — скорость должна снова вырасти.
