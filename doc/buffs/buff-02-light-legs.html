Лёгкие ноги

Увеличивает скорость передвижения на 25% за каждый выбор. Носиться между столами станет быстрее, но и прицельно бросать на скорости — сложнее.

buff_id: "movement_speed_positive" бафф · зелёная весь раунд · стакается реализовано

Эффект

⚡

Дополнительная скорость +0.25 за выбор

Аддитивная добавка current_additional_speed живёт в RoundController. Скрипт движения прибавляет её к базовой скорости: move_speed + current_additional_speed, но не ниже 1.

Без баффа+0move_speed
1-й выбор+0.25move_speed + 0.25
2-й выбор+0.50move_speed + 0.50

Схема работы

1. ВыборКарточка выбрана — apply_buff("movement_speed_positive").
→
2. Бонусcurrent_additional_speed += 0.25.
→
3. Движениеspeed = max(1, move_speed + current_additional_speed).
→
4. БегИгрок двигается быстрее. Выбор снова — ещё быстрее.
Из Unity

Аналог модификатора стата: current_additional_speed — как float-поле на GameManager, которое прибавляется к moveSpeed персонажа каждый кадр.

План внедрения

  1. Scripts/Round/round_controller.gd

    Дополнительная скорость + apply_buff()

    Рядом живёт красный «Тяжёлые ноги» (movement_speed_negative) — тот же стат, только вниз.

    round_controller.gd — скорость
    var current_additional_speed : float = 0

func apply_buff(buff_id: String):
	match buff_id:
		"extra_points":
			points_per_paper += 1
		"movement_speed_positive":
			current_additional_speed += 0.25
		"movement_speed_negative":
			current_additional_speed -= 0.5
	return
  2. Scripts/Player/player_movement.gd

    Применяем добавку

    Скрипт движения берёт ссылку на раунд в _ready() и прибавляет стат к базовой скорости. Пол ограничен: скорость никогда не упадёт ниже 1.

    player_movement.gd — применение
    var round_controller : RoundController

func _ready() -> void:
	camera = player.get_node("Camera3D")
	round_controller = get_tree().get_first_node_in_group("round_controller")

func _physics_process(_delta: float) -> void:
	# ...
	var speed = controller.move_speed
	speed = max(1, speed + round_controller.current_additional_speed)
	player.velocity = move_dir * speed
	player.move_and_slide()
  3. Scripts/Round/round_controller.gd

    Сброс в новом раунде (доделать)

    Сейчас reset_round() ещё не трогает current_additional_speed. По правилам баффов новый раунд должен обнулять стат.

    round_controller.gd — reset_round()
    func reset_round() -> void:
	current_additional_speed = 0
	# ...

Интерактив: беги и выбирай бафф

Зажми кнопку мыши на поле — человечек побежит к урне. Выбирай «Лёгкие ноги» и смотри, как растёт скорость.

Как проверить в игре

  1. Запусти Scenes/World.tscn, добудь карточки бросками.
  2. Выбери «Лёгкие ноги» — игрок должен заметно ускориться.
  3. Выбери ещё раз — скорость должна снова вырасти.
