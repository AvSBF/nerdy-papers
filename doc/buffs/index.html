Баффы Nerdy Papers

Игрок выбирает карточку после каждого цикла бросков. Один выбор — один бафф. Каждый бафф действует весь раунд, а повторный выбор усиливает его.

Правила

Общие правила всех баффов

Баффы не бывают на время: каждый действует до конца раунда (до проигрыша — не выполнил квоту). Повторный выбор того же баффа усиливает его (стакается). Новый раунд обнуляет все баффы. Зелёная карточка = плюс, красная = минус.

Зелёные баффы

Бонусные очкиреализовано

Каждая бумажка приносит на 1 очко больше (1 → 2 → 3…).
