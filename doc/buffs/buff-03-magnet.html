Магнит

Бумажка в полёте слегка притягивается к ближайшей урне с её типом. Не решает за тебя, но прощает неточные броски — особенно полезно с дальней дистанции.

buff_id: "magnet" бафф · зелёная весь раунд · стакается реализовано

Эффект

🧲

Пружина к правильной урне

Пока бумага летит свободно, она испытывает пружинную силу к ближайшей урне с подходящим типом: F = k·Δ − c·v. Сила magnet_strength растёт с каждым выбором, но радиус действия ограничен — с другой стороны комнаты не затянет.

Без баффаполёт прямойфизика не трогается
С баффомсила пружиныF = k·Δ − c·v

Схема работы

1. Выборapply_buff("magnet") — сила растёт.
→
2. БросокБумага в свободном полёте (не в руке).
→
3. ПружинаНашлась правильная урна в радиусе — сила тянет бумагу к ней.
→
4. ПопаданиеБумага засчитана, цикл повторяется.
Из Unity

Аналог AddForce в FixedUpdate к ближайшему объекту. Пружина в Godot делается в _integrate_forces — это прямой доступ к шагу физики RigidBody, как Rigidbody.AddForce в Unity.

	match buff_id:
		"magnet":
			magnet_strength += 2.0
  2. Scripts/Paper/paper.gd

    Пружина в _integrate_forces

    Сила прикладывается только в свободном полёте — когда бумага не летит в руку и не удерживается. Демпфирование гасит раскачку, чтобы бумага не «звенела».

    paper.gd — магнит
    func _integrate_forces(state: PhysicsDirectBodyState3D) -> void:
	if global_position.y < KILL_Y:
		queue_free()
		return
	if _flight_target != null:
		# полёт в руку (как сейчас)
		return
	elif _held and _hold_point != null:
		# удержание (как сейчас)
		return
	_apply_magnet(state)   # свободный полёт

func _apply_magnet(state: PhysicsDirectBodyState3D) -> void:
	var round := get_tree().get_first_node_in_group("round_controller")
	if round == null or round.magnet_strength <= 0.0:
		return
	var target := _nearest_correct_storage()
	if target == null:
		return
	var offset := target.global_position - global_position
	if offset.length() > MAGNET_RADIUS:
		return
	var spring := offset.normalized() * round.magnet_strength
	var damping := -linear_velocity * 0.6
	state.apply_central_force(spring + damping)

func _nearest_correct_storage() -> Node3D:
	var best : Node3D = null
	var best_dist := INF
	for storage in get_tree().get_nodes_in_group("paper_storage"):
		if storage.paper_type != paper_type:
			continue
		var d := global_position.distance_to(storage.global_position)
		if d < best_dist:
			best_dist = d
			best = storage
	return best

Интерактив: траектория с магнитом

Бумажка летит справа налево к урне. Включи магнит — траектория загнётся к цели.

интерактивпружина к урне

Как проверить в игре

  1. Выбери «Магнит» после появления карточек.
  2. Кинь бумажку мимо урны, но не слишком далеко — она должна довернуться к правильной урне.
  3. Кинь сильно в сторону — далёкий бросок магнит не спасёт (радиус ограничен).
