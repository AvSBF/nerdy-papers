Тяжёлые ноги

Скорость передвижения падает на 0.5 за каждый выбор. Ты всё ещё можешь успеть, но бегать придётся меньше.

buff_id: "movement_speed_negative" дебафф · красная весь раунд · стакается реализовано

Эффект

🪨

Дополнительная скорость −0.5 за выбор

Тот же стат current_additional_speed, что у «Лёгких ног», только вниз — и сильнее: −0.5 против +0.25. Скорость не уходит ниже 1: speed = max(1, move_speed + current_additional_speed).

Без дебаффа+0move_speed
1-й выбор−0.5move_speed − 0.5
2-й выбор−1.0move_speed − 1.0

Схема работы

1. Выборapply_buff("movement_speed_negative").
→
2. Минусcurrent_additional_speed -= 0.5.
→
3. Движениеspeed = max(1, move_speed + current_additional_speed).

План внедрения

  1. Scripts/Round/round_controller.gd

    Ветка в apply_buff()

    Дебафф живёт рядом с «Лёгкими ногами» в одном match — тот же стат, тот же сброс.

    round_controller.gd — скорость
    var current_additional_speed : float = 0

func apply_buff(buff_id: String):
	match buff_id:
		"extra_points":
			points_per_paper += 1
		"movement_speed_positive":
			current_additional_speed += 0.25
		"movement_speed_negative":
			current_additional_speed -= 0.5
	return
  2. Scripts/Player/player_movement.gd

    Применение стата

    player_movement.gd
    var round_controller : RoundController

func _ready() -> void:
	camera = player.get_node("Camera3D")
	round_controller = get_tree().get_first_node_in_group("round_controller")

func _physics_process(_delta: float) -> void:
	# ...
	var speed = controller.move_speed
	speed = max(1, speed + round_controller.current_additional_speed)
	player.velocity = move_dir * speed
	player.move_and_slide()
  3. Scripts/Round/round_controller.gd

    Сброс в новом раунде (доделать)

    Сейчас reset_round() ещё не трогает current_additional_speed. По правилам баффов новый раунд должен обнулять стат.

    round_controller.gd — reset_round()
    func reset_round() -> void:
	current_additional_speed = 0
	# ...

Как проверить в игре

  1. Выбери «Тяжёлые ноги» — игрок должен замедлиться.
  2. Выбери ещё раз — ещё медленнее, но не до нуля.
