Вторая рука

Игрок держит больше бумажек одновременно. Больше ноши — меньше пробежек к столу-раздатчику.

buff_id: "second_hand" бафф · зелёная весь раунд · стакается

Эффект

✋

+1 слот бумажек за выбор

Сейчас игрок может нести 1 бумажку. Бафф добавляет слоты: 1 → 2 → 3. Потолок — 3, чтобы стек не ломал физику стопки.

Без баффа1 бумажкаmax_held_papers = 1
1-й выбор2 бумажкиmax_held_papers = 2
2-й выбор3 бумажкиmax_held_papers = 3

Схема работы

1. Выборapply_buff("second_hand").
→
2. Слотыhand_slots += 1 (потолок 3).
→
3. ПодборИнтерактор разрешает брать, пока рук меньше hand_slots.
Из Unity

Аналог maxHeldItems на игроке. Godot уже умеет стопку: _stack_offset_for_index() раскладывает бумажки по вертикали.

План внедрения

  1. Scripts/Round/round_controller.gd

    Слоты руки

    round_controller.gd — слоты
    const MAX_HAND_SLOTS : int = 3
var hand_slots : int = 1

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"second_hand":
			hand_slots = mini(MAX_HAND_SLOTS, hand_slots + 1)
  2. Scripts/Player/player_interactor.gd

    Читаем слоты из раунда

    Экспорт max_held_papers заменяем ссылкой на раунд. Проверка при подборе остаётся той же.

    player_interactor.gd — лимит руки
    var _round : Node

func _ready() -> void:
	_round = get_tree().get_first_node_in_group("round_controller")

func max_held_papers() -> int:
	return _round.hand_slots if _round != null else 1

func _on_paper_interacted(paper: Node) -> void:
	var body := paper as Paper
	if body == null or _flying_paper != null or _throwing \
			or held_papers.size() >= max_held_papers():
		return
	# ...
  3. Scripts/Round/round_controller.gd

    Сброс в новом раунде

    round_controller.gd — reset_round()
    func reset_round() -> void:
	hand_slots = 1
	# ...

Интерактив: наполняй руку

Сначала в руке 1 слот. Выбери бафф, потом бери бумажки — они заполняют стопку сверху вниз.

интерактивслоты руки

Как проверить в игре

  1. Выбери «Вторую руку».
  2. Подойди к столу и возьми бумажку — теперь можно взять ещё одну (подсказка «E» остаётся).
  3. Бросай по одной — стопка должна схлопываться без телепортов.
