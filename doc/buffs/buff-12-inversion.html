Инверсия

Обе оси камеры инвертированы на весь раунд. Управление становится непривычным, но преодолимым — нужно просто перевернуть мысль.

buff_id: "inversion" дебафф · красная весь раунд · не стакается

Эффект

↩️

Сдвиг мыши × −1 по X и Y

Один булевый флаг invert_look. Пока он включён, camera_rotator берёт движение мыши с обратным знаком. Флаг уже не выключить — только новый раунд.

Без дебаффаобычный поворот−motion.relative × sens
С дебаффоминвертированный+motion.relative × sens

Схема работы

1. Выборapply_buff("inversion").
→
2. Флагinvert_look = true.
→
3. КамераРотатор умножает движение мыши на −1.

План внедрения

  1. Scripts/Round/round_controller.gd

    Флаг и ветка

    round_controller.gd — инверсия
    var invert_look : bool = false

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"inversion":
			invert_look = true
  2. Scripts/Player/camera_rotator.gd

    Знак движения мыши

    camera_rotator.gd — ротация
    var _round : Node

func _ready() -> void:
	_round = get_tree().get_first_node_in_group("round_controller")

func _unhandled_input(event: InputEvent) -> void:
	if Input.mouse_mode != Input.MOUSE_MODE_CAPTURED:
		return
	if event is InputEventMouseMotion:
		var motion := event as InputEventMouseMotion
		var sign := -1.0 if _round.invert_look else 1.0
		player.rotate_y(sign * -motion.relative.x * controller.mouse_sensitivity)
		pitch = clampf(
			pitch + sign * -motion.relative.y * controller.mouse_sensitivity,
			deg_to_rad(controller.min_pitch),
			deg_to_rad(controller.max_pitch)
		)
		rotation.x = pitch
  3. Scripts/Round/round_controller.gd

    Сброс в новом раунде

	invert_look = false

Интерактив: инвертированная мышь

Веди мышью по полю — точка движется за курсором. Включи инверсию: точка начнёт убегать в противоположную сторону.

Как проверить в игре

  1. Выбери «Инверсию».
  2. Поводи мышью — камера должна вращаться в обратную сторону.
  3. Попробуй бросить бумажку — понадобится пара попыток, чтобы привыкнуть.
