Ледяная мышь

Чувствительность камеры падает. Двигаешь мышью — экран еле поворачивается. Точный бросок превращается в игру на нервы.

buff_id: "icy_mouse" дебафф · красная весь раунд · стакается

Эффект

🧊

mouse_sensitivity × 0.75 за выбор, минимум ×0.4

Множитель mouse_sensitivity_multiplier умножается на базовую чувствительность в camera_rotator. Потолок не даёт совсем «заморозить» камеру.

Без дебаффа×1.00mouse_sensitivity
1-й выбор×0.75чувствительность ниже

Схема работы

1. Выборapply_buff("icy_mouse").
→
2. Минусmouse_sensitivity_multiplier *= 0.75, минимум 0.4.
→
3. КамераРотатор умножает движение мыши на множитель.

План внедрения

  1. Scripts/Round/round_controller.gd

    Множитель чувствительности

    round_controller.gd — мышь
    const SENS_FLOOR : float = 0.4
var mouse_sensitivity_multiplier : float = 1.0

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"icy_mouse":
			mouse_sensitivity_multiplier = maxf(
				SENS_FLOOR,
				mouse_sensitivity_multiplier * 0.75
			)
  2. Scripts/Player/camera_rotator.gd

    Применяем множитель

    camera_rotator.gd — ротация
    var _round : Node

func _ready() -> void:
	_round = get_tree().get_first_node_in_group("round_controller")

func _unhandled_input(event: InputEvent) -> void:
	if Input.mouse_mode != Input.MOUSE_MODE_CAPTURED:
		return
	if event is InputEventMouseMotion:
		var motion := event as InputEventMouseMotion
		var sens := controller.mouse_sensitivity * _round.mouse_sensitivity_multiplier
		player.rotate_y(-motion.relative.x * sens)
		pitch = clampf(
			pitch - motion.relative.y * sens,
			deg_to_rad(controller.min_pitch),
			deg_to_rad(controller.max_pitch)
		)
		rotation.x = pitch

Интерактив: вялая мышь

Веди мышью по полю — прицел движется. Каждый дебафф делает его всё медленнее.

интерактивчувствительность

Как проверить в игре

  1. Выбери «Ледяную мышь» — камера должна вращаться заметно медленнее.
  2. Выбери ещё раз — почти замрёт, но не полностью.
