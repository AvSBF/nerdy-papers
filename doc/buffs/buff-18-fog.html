Туман

Экран слегка трясётся и размывается. Прицеливаться по дальним урнам — как в тумане: вроде видно, а попасть сложно.

buff_id: "fog" дебафф · красная весь раунд · не стакается

Эффект

🌫️

Тряска + размытие картинки

Поверх экрана — оверлей FogOverlay (CanvasLayer): полноэкранный ColorRect с шейдером. Каждый кадр его смещение дёргается случайно, а края размываются виньеткой.

Без дебаффачистый экран—
С дебаффомтряска + виньеткакаждый кадр

Схема работы

1. Выборapply_buff("fog") — fog_enabled = true.
→
2. КадрОверлей в _process дёргает offset случайно.
→
3. ЭффектКартинка под ним трясётся и мылится.

План внедрения

  1. Scenes/UI/FogOverlay.tscn (новая)

    Оверлей с шейдером

    CanvasLayer → ColorRect на весь экран. Материал — CanvasItem-шейдер с лёгким blur и виньеткой; смещение задаётся из скрипта.

    FogOverlay.tscn — дерево
    FogOverlay : CanvasLayer
└── FogRect : ColorRect
    └── material : ShaderMaterial (blur + vignette)
  2. Scripts/UI/fog_overlay.gd (новый)

    Тряска из _process

    fog_overlay.gd
    extends CanvasLayer

var _round : Node
var _mat : ShaderMaterial

func _ready() -> void:
	_round = get_tree().get_first_node_in_group("round_controller")
	_mat = $FogRect.material as ShaderMaterial

func _process(_delta: float) -> void:
	var enabled : bool = _round.fog_enabled
	$FogRect.visible = enabled
	if not enabled:
		return
	_mat.set_shader_parameter("offset", Vector2(
		randf_range(-0.01, 0.01),
		randf_range(-0.01, 0.01)
	))
  3. Scripts/Round/round_controller.gd

    Включение и сброс

    round_controller.gd — туман
    var fog_enabled : bool = false

func apply_buff(buff_id: String) -> void:
	match buff_id:
		"fog":
			fog_enabled = true

func reset_round() -> void:
	fog_enabled = false

Как проверить в игре

  1. Выбери «Туман».
  2. Поводи камерой — картинка должна заметно дрожать и мылиться.
  3. Попробуй попасть в дальнюю урну — должно быть ощутимо сложнее.
