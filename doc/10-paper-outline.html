Окантовка бумаги при наведении

Навёл курсор на бумагу — вокруг неё загорается белая окантовка. Внутри — копия коробки, надутая чуть больше, с одним cull_front и обычным depth-test. Разбираем, почему этих двух строк хватает, на интерактивной 3D-схеме.

Задача

При наведении на бумагу должна появляться внешняя белая окантовка вокруг силуэта. Требования:

  • окантовка видна поверх объектов позади бумаги (пол, стол, бумажки в стопке);
  • но не закрашивает саму бумагу ни под каким углом.

Никакого «нарисовать рамку поверх экрана»: окантовка — это настоящий 3D-меш, поэтому она честно реагирует на ракурс и умеет прятаться за объектами, которые ближе к камере.

Ховер уже есть

Детект наведения мы не пишем — он уже работает. Каждый физический тик Scripts/Player/player_interactor.gd делает рейкаст из камеры и при смене цели испускает сигнал target_changed. Бумага входит в группу "paper" — её добавляет paper_creator.gd при спавне. То есть нам нужен только «выход»: показать/спрятать окантовку у текущей цели.

Идея: перевёрнутый корпус

Классический приём для контурной подсветки — перевёрнутый корпус (inverted hull).

  1. Берём точную копию меша бумаги (та же коробка).
  2. Увеличиваем её — scale — это «корпус».
  3. Красим корпус в белый.
  4. Переворачиваем куллинг (cull_front) и оставляем depth-test как есть.

Корпус — это замкнутая коробка чуть больше бумаги. Он «выглядывает» из-за силуэта только полоской, а всё, что лежит за передней поверхностью самой бумаги, закрывается ей через depth-test. Итог — белое кольцо вокруг контура, которое никогда не заливает саму бумагу.

Аналогия

Представь рамку для фотографии: это тот же лист, только чуть больше и белый, положенный под фото. Из-под фото видна только каёмка по краям.

Шейдер: cull_front

Весь «умный» код — в двух строках. Файл Shaders/paper_outline.gdshader:

Shaders/paper_outline.gdshader
shader_type spatial;
render_mode unshaded, cull_front, shadows_disabled;

void fragment() {
	ALBEDO = vec3(1.0);   // чисто белый
	ALPHA = 1.0;
}

Что тут происходит:

  • unshaded — не нужен свет, корпус всегда ровно белый.
  • cull_front — ключевая строка. Обычный куллинг (cull_back) рисует грани, смотрящие на камеру, и отбрасывает задние. cull_front — наоборот: рисует только грани, отвернутые от камеры. Для корпуса это значит, что мы видим только ту его часть, что выпирает за силуэт бумаги.
  • shadows_disabled — корпус не бросает тень и не ловит её.
cull_front простыми словами

У каждой грани 3D-объекта есть направление (нормаль). GPU не рисует грани «спиной к нам», чтобы не тратить время на невидимое. cull_front инвертирует выбор: рисуем только «задние» грани. Снаружи закрытая коробка при таком куллинге выглядит почти пустой — видны лишь те куски, которые торчат из-за краёв. Именно эти торчащие куски и образуют окантовку.

Узел Outline в сцене

Трансформ у Outline тот же, что у MeshInstance3D, а увеличение задаётся не в сцене, а скриптом — через scale.

Скрипт paper_outline.gd

Он хранит толщину и умеет включать/выключать окантовку:

Scripts/Paper/paper_outline.gd
class_name PaperOutline
extends MeshInstance3D

@export var thickness : Vector3 = Vector3(0.06, 0.15, 0.06)

func _ready() -> void:
	visible = false
	scale = Vector3.ONE + thickness

func set_highlighted(on: bool) -> void:
	visible = on

Толщина по осям задаётся отдельно: бумага плоская, поэтому по вертикали y корпус надут сильнее — окантовка читается и когда смотришь на лист почти сбоку.

Связка с ховером

В paper.gd добавлен метод set_highlighted, а в player_interactor.gd подсветка переключается при смене цели:

Scripts/Player/player_interactor.gd
func _update_target() -> void:
	var target := _find_target()
	if target == current_target:
		return
	_set_target_highlight(current_target, false)
	current_target = target
	_set_target_highlight(current_target, true)
	target_changed.emit(current_target)

func _set_target_highlight(node: Node, on: bool) -> void:
	if node != null and node.is_in_group("paper"):
		var paper := node as Paper
		if paper:
			paper.set_highlighted(on)

Старая бумага гасится, новая — зажигается. При подборе (_on_paper_interacted) подсветка снимается сразу, чтобы окантовка не летела в руке. Пока бумага держится, её коллизия выключена, рейкаст её не видит — подсветка и не появится.

Почему «поверх других объектов»

Полоса корпуса выступает за силуэт бумаги и лежит перед тем, что позади (пол, стол, другие бумажки). Поэтому она видна поверх фона. А вот сквозь объект, который ближе к камере, она не пробивается — и это правильно: такой объект был бы наведён рейкастом, а не бумага.

А если хочется сквозь стены?

Наш вариант — честный 3D: окантовка прячется за ближними объектами. Если захочется «рентген» — чтобы окантовка светилась даже через стену — придётся выключить depth-test (depth_test_disabled) и discard-ить фрагменты, которые глубже поверхности бумаги. Проще всего через отдельный маленький SubViewport, куда рендерится только глубина бумаги. Это дороже по производительности и нужно в этой игре едва ли: наведённая рейкастом бумага и так первый объект на луче.
