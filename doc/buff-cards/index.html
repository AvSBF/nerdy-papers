Буфф-карточки после бросков

Когда игрок закинул нужное количество бумажек в ящики (число каждый раз разное), поверх экрана появляются 3 карточки — зелёные и красная. Игрок кликает одну, карточки уходят, игра продолжается. Баффы пока — заглушки.

Идея

Это первый настоящий «геймплейный цикл» проекта: механика, которая реагирует на действия игрока и ставит перед ним выбор. Пока баффы ничего не делают, но каркас уже полноценный:

  • счётчик закинутых бумажек с плавающим порогом;
  • пауза мира и показ карточек;
  • клик по карточке → выбор → игра продолжается.

Зелёная карточка = бафф (плюс), красная = дебафф (минус). Это цветовой язык, который потом наполним настоящими эффектами.

Лёгкие ноги
зелёная · бафф · заглушка
Тяжёлые руки
красная · дебафф · заглушка

Поток игры

Вся фича — это один цикл из четырёх шагов:

1. БросокИгрок кидает бумажку в ящик, ящик шлёт сигнал paper_deposited.
→
2. ПорогМенеджер считает броски. Достал плавающее число — срабатывает.
→
3. ВыборИгра на паузе, поверх экрана 3 карточки.
→
4. КликКлик по карточке — карточки исчезают, игра продолжается.
Из Unity

Это аналог GameManager + UI-панели. Сигнал paper_deposited — как UnityEvent, менеджер — как скрипт, подписанный на события, а get_tree().paused — как Time.timeScale = 0.

Сигнал от ящика

Раньше ящик просто увеличивал свой счётчик. Теперь он ещё и сообщает об этом миру. Добавлено три строки:

Scripts/Paper Storage/paper_storage.gd
signal paper_deposited(count: int)

func _ready() -> void:
	add_to_group("paper_storage")          # менеджер найдёт ящики по группе
	# ...

func _on_body_entered(body: Node3D) -> void:
	# ...
	count += 1
	body.queue_free()
	# ...
	paper_deposited.emit(count)            # оповестить всех подписчиков

add_to_group("paper_storage") — это «тег» из Unity: любой узел может найти все ящики через get_tree().get_nodes_in_group(...).

Менеджер карточек

Мозг фичи. Считает броски, решает, когда показать карточки, и убирает их после клика.

Scripts/UI/buff_card_manager.gd
extends CanvasLayer

signal card_chosen(card_type: String)

@export var card_scene : PackedScene
@export var required_min : int = 3      # порог плавающий:
@export var required_max : int = 6      # каждый раз новый

func _ready() -> void:
	process_mode = Node.PROCESS_MODE_ALWAYS   # работаем даже на паузе
	overlay.visible = false
	for storage in get_tree().get_nodes_in_group("paper_storage"):
		storage.paper_deposited.connect(_on_paper_deposited)
	_roll_required()

func _on_paper_deposited(_count: int) -> void:
	if _cards_active:
		return
	_deposits_total += 1
	if _deposits_total >= _required:
		_show_cards()

func _roll_required() -> void:
	_required = randi_range(required_min, required_max)

Показ и уборка карточек — это вкл/выкл паузы и курсора:

buff_card_manager.gd — показ и скрытие
func _show_cards() -> void:
	_cards_active = true
	get_tree().paused = true               # мир замирает
	Input.mouse_mode = Input.MOUSE_MODE_VISIBLE
	_build_cards()
	overlay.visible = true

func _on_card_pressed(card: BuffCard) -> void:
	card_chosen.emit(card.card_type)
	_hide_cards()

func _hide_cards() -> void:
	overlay.visible = false
	get_tree().paused = false              # игра продолжается
	Input.mouse_mode = Input.MOUSE_MODE_CAPTURED
	_deposits_total = 0
	_roll_required()                       # следующий порог — новый
	_cards_active = false

process_mode = PROCESS_MODE_ALWAYS — ключевая строка: на паузе обычные узлы перестают получать ввод, а этот слой продолжает. Иначе кнопки не отреагируют на клик.

Сама карточка

Карточка — это Button с настраиваемым внешним видом. Метод setup() получает словарь с данными и раскрашивает себя в зелёный или красный:

Scripts/UI/buff_card.gd
class_name BuffCard
extends Button

signal chosen(card: BuffCard)

const GREEN_COLOR := Color(0.16, 0.55, 0.32)
const RED_COLOR := Color(0.65, 0.2, 0.18)

func setup(data: Dictionary) -> void:
	card_type = str(data.get("type", "green"))
	var color := GREEN_COLOR if card_type == "green" else RED_COLOR
	top_stripe.color = color
	type_label.text = "БАФФ" if card_type == "green" else "ДЕБАФФ"
	title_label.text = str(data.get("title", "Без названия"))
	desc_label.text = str(data.get("desc", "Заглушка"))

Данные — это пул заглушек в менеджере. Пока это просто словари с текстом:

buff_card_manager.gd — пулы заглушек
const GOOD_POOL : Array[Dictionary] = [
	{"title": "Лёгкие ноги", "desc": "Заглушка. Скорость пока не меняется."},
	{"title": "Сильный бросок", "desc": "Заглушка. Дальность броска пока не меняется."},
]

const BAD_POOL : Array[Dictionary] = [
	{"title": "Тяжёлые руки", "desc": "Заглушка. Скорость пока не меняется."},
	{"title": "Дрожь в руках", "desc": "Заглушка. Точность пока не меняется."},
]

Позже вместо пула появится Resource-данные (как ScriptableObject), а в card_chosen — подпишется логика реальных баффов.

Интерактив: цикл карточек

Жми «Закинуть бумажку» и смотри, как работает порог и появление карточек. Порог каждый раз новый.

Как проверить в игре

  1. Запусти сцену Scenes/World.tscn.
  2. Возьми бумажки со стола (клавиша E) и брось в ящик (G).
  3. После нужного числа бросков (от 3 до 6, случайно) появятся 3 карточки.
  4. Кликни любую — карточки исчезнут, игра продолжится, порог заново случайный.
  5. Порог можно покрутить на узле BuffCardUI: required_min / required_max.
  6. Быстрая проверка без бросков: открой дебаг-меню (F1) и нажми «Показать карточки» — менеджер вызовет force_show().
